## Estructura

```text
unidad-<n>/
├── README.md              Índice de la unidad
├── apes/                  Prácticas entregadas
│   └── ape-<m>-<tema>/    Una carpeta por práctica
└── apuntes/               Resúmenes de clase y guías de estudio
```

Cada unidad separa dos tipos de contenido:

| Tipo | Qué contiene |
| --- | --- |
| **Prácticas** (`apes/ape-<m>-<tema>/`) | Lo entregado en cada Actividad Práctico-Experimental: `README.md` con el proceso, `documento/` con el informe y, cuando aplica, el código y la simulación. |
| **Apuntes** (`apuntes/`) | Material de estudio propio: resúmenes de las clases en Markdown y guías PDF con diagramas. No forman parte de ninguna entrega. |
