## Cómo estudiar

1. Lee la **idea central** y el diagrama de cada apunte.
2. Recorre la **guía PDF** (A4 vertical, diagramas de pasos) y cierra con **Ideas para recordar**; si algo no queda claro, abre el resumen en Markdown.
